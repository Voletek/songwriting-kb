## Artist Signature DNA

Across the catalog, the recurring identity:

| Element | Prevalence |
|---|---|
| Male baritone / baritenor lead (A2-E4) | Nearly universal — the default voice |
| Minor keys (F#m, Dm, Em, Fm, Bm, Cm, Gm, Ebm) | ~85% |
| "Cinematic" descriptor | ~70% |
| East Tennessee / Appalachian vocal inflection | The mountain-gothic cluster |
| Genre fusion (fringe + accessible) | The newer material |
| Banjo + cello pairing | The Appalachian cluster |
| Progressive build (sparse intro → massive finale) | Very common structural signature |
| Key lift to major on resolution | Reserved for emotional payoffs (Rikan Fm→Ab, Both Names Am→C) |
| "No autotune / no clean polish" | Recurring — rawness is valued |
| Female counter-voice / duet | The duet cluster |
| 4/4 | Universal |

**The core artist identity** is: Appalachian-rooted male vocals + genre fusion + dark cinematic production + build dynamics.
